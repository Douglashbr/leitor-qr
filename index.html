Ler QR code de foto ou print

Leitor de QR code online e grátis. Escolha uma foto ou print, cole com Ctrl+V ou arraste para cá. A leitura acontece no seu aparelho: a imagem não é enviada a lugar nenhum.

Instale o leitor na tela inicial para abrir como um app, mesmo sem internet.

Nenhuma imagem ainda.

Dica: no computador, Ctrl+V cola um print direto.

Histórico

    Como ler um QR code de uma imagem

    1. Escolha a imagem. Toque em "Escolher imagem" e selecione um print, uma foto da galeria ou um arquivo baixado. No computador, cole com Ctrl+V ou arraste o arquivo.
    2. Veja o conteúdo. Cada QR code encontrado ganha um número na imagem e um cartão com o que ele contém.
    3. Copie ou abra. Copie o código PIX, a senha do Wi‑Fi ou o link, ou abra o link direto, depois de conferir o alerta de segurança.

    O que o leitor reconhece

    PIX copia e cola
    Recebedor, cidade, valor, chave e identificador, com verificação do código para detectar QR code alterado ou incompleto.
    Wi‑Fi
    Nome da rede, senha e tipo de segurança, com botão para copiar a senha.
    Links
    Mostra o site de destino e avisa sobre sinais comuns de golpe, como links encurtados e endereços que imitam bancos.
    Contatos e outros
    Cartões de visita (vCard), e‑mail, telefone, SMS, localização e texto simples.

    Perguntas frequentes

    A imagem é enviada para algum servidor?

    Não. A leitura é feita no próprio aparelho, pelo navegador. A imagem não sai do seu celular ou computador.

    Precisa instalar algum aplicativo?

    Não. O leitor funciona direto no navegador. Se quiser, adicione à tela inicial para abrir como um app, inclusive sem internet.

    Dá para ler o QR code de um PIX recebido por imagem?

    Sim. Escolha a imagem do PIX e o leitor mostra os dados da cobrança e o código copia e cola para colar no app do banco. Confira sempre o nome do recebedor antes de pagar.

    E se a imagem tiver mais de um QR code?

    O leitor procura todos os códigos da imagem e mostra cada um separado, numerado na ordem em que aparecem.

    Não encontrou o QR code. O que fazer?

    Use uma imagem mais nítida, recorte a área perto do código ou tire um print com o QR code maior na tela. Imagens muito borradas ou com o código cortado não podem ser lidas.

    Como saber se o link de um QR code é golpe?

    O leitor avisa quando o link é encurtado, não usa https, aponta para um IP ou cita um banco no começo do endereço enquanto o site real é outro. Mesmo sem alerta, confira o endereço antes de digitar senhas ou pagar.
